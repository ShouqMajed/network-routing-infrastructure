# Network Topology & Routing Infrastructure

A Cisco Packet Tracer networking project demonstrating the design and configuration of a multi-router network using **RIPv2, IP addressing, and subnetting** to enable communication across multiple networks.

## Project Overview

This project implements a network topology consisting of multiple LANs connected through three routers.

The network devices were configured with appropriate IP addresses and routing settings, followed by connectivity testing to verify communication within local networks and across different networks.

## Network Architecture

The topology includes:

- 3 Cisco routers: R1, R2, and R3
- Multiple LAN segments
- Cisco switches
- Multiple end-user PCs
- WAN connections between routers

## Routing Configuration

**RIPv2 (Routing Information Protocol Version 2)** was configured on the routers to dynamically exchange routing information between the connected networks.

The routing configuration allows devices located on different LANs to communicate through the multi-router infrastructure.

## Network Configuration

The project includes:

- IP address configuration
- Subnet mask configuration
- Default gateway configuration
- Router interface configuration
- RIPv2 dynamic routing
- LAN and WAN connectivity

## Connectivity Testing

Network connectivity was verified using **Ping** tests.

Testing included:

- Communication between devices within the same LAN
- Communication between devices located on different networks
- Verification of end-to-end connectivity after configuring RIPv2

Successful ping tests confirmed that routing between the different networks was functioning correctly.
